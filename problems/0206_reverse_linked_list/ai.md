# AI Solution — LC 0206 Reverse Linked List

### 1) Restatement  
Given the head node of a singly linked list, reverse the list completely and return the new head node. For example:  
Input: `1 → 2 → 3 → 4 → 5 → None`  
Output: `5 → 4 → 3 → 2 → 1 → None`  

---

### 2) Key Insight  
To reverse a singly linked list, we need to redirect each node's `next` pointer to its previous node. This requires tracking three pointers during traversal:  
- **Previous node** (to link backwards)  
- **Current node** (being processed)  
- **Next node** (to preserve the rest of the list)  

---

### 3) Step-by-Step Approach  
1. **Initialize pointers**:  
   - `prev = None` (start before the head)  
   - `curr = head` (start at the first node)  
   - `next_node = None` (temporary storage for next node)  

2. **Traverse the list**:  
   - While `curr` is not `None`:  
     a. **Save next node**: Store `curr.next` in `next_node` to avoid losing the rest of the list.  
     b. **Reverse link**: Set `curr.next = prev` to point backwards.  
     c. **Advance pointers**: Move `prev` to `curr`, and `curr` to `next_node`.  

3. **Terminate**:  
   - When `curr` becomes `None`, `prev` is the new head.  

---

### 4) Pitfalls & Edge Cases Checklist  
- **Empty list**: If `head` is `None`, return `None`.  
- **Single-node list**: Returns itself (no reversal needed).  
- **Correct pointer handling**: Ensure `next_node` saves `curr.next` **before** modifying `curr.next`.  
- **Termination**: Final `prev` must be returned as the new head.  

---

### 5) Complexity  
- **Time**: O(n) — Traverse each node exactly once.  
- **Space**: O(1) — Uses constant extra space (three pointers).  

---

### 6) Reference Python Solution  
```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev = None
        curr = head
        
        while curr:
            next_node = curr.next  # Save next node
            curr.next = prev       # Reverse link
            prev = curr            # Move prev forward
            curr = next_node       # Move curr forward
        
        return prev  # New head
```

---

### 7) Short Alternatives (Optional)  
**Recursive Approach** (O(n) space for call stack):  
```python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head
        new_head = self.reverseList(head.next)
        head.next.next = head  # Reverse link for next node
        head.next = None       # Break original link
        return new_head
```  
**Note**: Recursion is elegant but less efficient for large lists (stack overflow risk). Iterative is preferred.
